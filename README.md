Personal Finance Tracker

This would be a CLI based personal finance tracker to monitor spending during my internship. It'll be built with Python, PostgreSQL and my goal is to show my understanding of OO design and functional programming – concepts learned in my CS3003 Class

Quick Description

This project tracks my income and expenses across different accounts and categories, and it'd tell us:

- Log transactions (amount, category, date, description)
- Set and monitor monthly budgets
- Get spending breakdowns by category
- Forecast future spending based on trends
- Receive budget alerts when approaching limits
